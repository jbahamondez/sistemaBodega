Plantilla y exportación

  • Una fila por FORMATO de empaque. Si un producto tiene varios formatos (display, caja, unidad), repetir los datos del producto en cada fila.
  • nombre_producto, codigo_barras y unidades_por_empaque son obligatorios. También se acepta la planilla real (Cod producto / Descripcion del producto (Nombre) / EAN / Cantidad).
  • codigo_producto es opcional pero recomendado: identifica al producto de forma estable entre importaciones.
  • tipo_empaque: DISPLAY, CAJA, UNIDAD u OTRO. Si falta, se deriva de las unidades (1 → Unidad; más de 1 → Caja x N).
  • unidades_por_empaque: entero mayor que 0 (cuántas unidades contiene la caja o display).
  • activo: SI o NO (vacío se interpreta como SI).
  • Los códigos de barras se tratan como texto: se conservan los ceros iniciales exactamente como se escriban.
